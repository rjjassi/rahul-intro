# Rahul Jaiswal — Intro Page

A single-page personal introduction site for sharing with a new team.

## Run locally

Open `index.html` in a browser.

## Publish free with GitHub Pages

1. Create a new public GitHub repository, e.g. `rahul-intro`.
2. Upload `index.html` and `README.md`.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. GitHub will provide your public Pages URL.

## Customize

Everything is contained in `index.html`. Replace any wording, add your LinkedIn/GitHub links, or update the technology list as needed.
